Website for Basils Gatukök, a local street food restaurant in Eskilstuna. 
The website shows the menu, opening hours and important information. 
Built to work on both desktop and mobile. 

https://basilsgatukok.se

I designed and developed this website myself for a real local business.
AI tools were used for structure and smaller tweaks and troubleshooting along the way, while
design and layout is my own work.
